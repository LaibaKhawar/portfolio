# Laiba Khawar — Portfolio

A responsive, static portfolio showcasing selected AI, data, web, academic, and professional work.

## Run locally

From this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

The FYP walkthrough video is stored locally in `assets/` and plays in an accessible modal. Professional experience is intentionally presented at a high level to protect confidential company and client information.
